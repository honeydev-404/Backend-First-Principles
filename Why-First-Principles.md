1.WHY WE ARE LEARNING BACKEND FROM FIRST PRINCIPLES?

There are various reasons why we are learning, some of them are :-
* We get an idea that how we can build Scalable, Reliable, Robust and Performant systems.
* Understand how Data is stored, processed and transferred.
* Understand how the machines interact through network.
* Helps with Debugging - we can understand how a system falls and what is the root cause of that faliure.
* Make it easier to learn the frameworks like NODE.JS, GO, POSTGRESQL, REDIS because you have already understood the basic concept of how it works.
* Understand how Request/Response Lifecycle works - from client -> server -> database -> response.

Summary in one sentense :-
- We learn backend from first principles so that we can get basic idea about what is happening underneath the abstraction and allows us to build, scale, debug and more efficient system rather than just simply knowing how to use frameworks.
