HTTPS/TLS :-
* SSL (Secure Socket Layer) :- It is a cryptograpic protocol design to secure communication between web browser and servers and it has been depriciated.
* TLS (Transport Layer Security) :- It was introduced as a Successor/enhancement of SSL Because it provided improved Security, Effitiency, and Perfomance and it is still widely used.
* HTTPS :- It is just HTTP transmitted over TLS-Secured connection.
