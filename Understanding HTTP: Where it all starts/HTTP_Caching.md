HTTP Caching :-
* HTTP caching is a mechanism in which previously fetched responses   are stored and reused for future requests.
* It has several advantages:-
* Reusablity -> It means that if we have to fetch the same data that we have fetched multiple time so it will be server from the cache not from the server so it decrease the server load.
* Speed -> We know from the basic idea that getting data from the cache is much faster than fetching it from the database so the browser stored the most frequent request and caches them.
* The cache state changes if we make some change it depends on the Last-Modified header.
