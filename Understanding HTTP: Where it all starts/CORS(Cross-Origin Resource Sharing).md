CORS (Cross-Origin Resource Sharing) :-
* CORS is a security mechanism that control which different origins/domains are allowed to access/read the server’s response.
* There are 2 outcomes depends on the security policies and the data that we are trying to fetch from the different domain.
* If the server allows the requesting origin through its CORS policy, the browser allows the client-side JavaScript to read the response.
* If the origin is not allowed, the browser blocks the response from being read by the client-side JavaScript.
