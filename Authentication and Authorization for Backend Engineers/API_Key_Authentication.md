
API Key Authentication :-
* API -> It stands for Application Programming Interface, is a set of rules and protocols that allows one server to send or recieve data with another server interchangibly.
* API Keys -> API keys are the unique strings of letter and number which act as a digital password when one application want to talk to another.
* And API Keys are only for machine-to-machine communication and depends on the programmtic authentication rather than human authentication.
*  they included built-in permissions/scopesand expiration controls and also have one header like {Authorization : Bearer _Token_} .
