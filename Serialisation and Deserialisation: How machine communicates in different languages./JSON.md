
What is JSON :-
* JSON -> JavaScript Object Notation
* It is a very Readable and Human-Friendly interchange format of data.
* Note -> Don’t think that JSON is only used in JavaScript it is also made for different languages and they can also read/write it.
    * Suppose and example we have some data :-
        -  
        - {
        -   "name": "Honey",
        -   "age": 16,
        -   "student": true,
        -   "skills": ["Go", "SQL"]
        - }
        - 
    * So in this example se one pattern that the Data is stored in {KEY : VALUE} Pair so this is main feature that make JSON more readable.
        - They have many data types like String, Numbers, Arrays and Boolean values etc.
