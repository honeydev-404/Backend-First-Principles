
Serialisation :-
* They process of converting Data in a Standard format which both the client and server can use to exchange/store data this is called Serialisation.
* There are many formats in which the Data can be transferred like JSON,XML,YAML.
* Most of the time you will see JSON in use because of its Easy and Lightweight syntax and Universal Capabilities.
* The flow goes like -> Client -> Data -> Serialise -> Server.

Deserialisation :-
* Now the client side work is done (Serialisation) now the data comes to Backend application in the JSON format now the server deserialise the data that was sent by the client which was in serialised format (JSON) and now it can process the data.
* The server deserializes the serialized data received from the client so that the application can process it.

Complete Flow of Serialisation -> Deserialisation Process :-
 	Client -> Data -> Serialise -> Server -> Deserialise -> The DATA is now understood by the system -> Response.

Serialisation Formats :-
	Text-Based Formats -> 
1. JSON
2. YAML
3. XML

	Binary Format ->
1. Protocol Buffers.
