Nested Routes ->
* Nested Routes tell us about the relation of something with something like user -> post -> specific post, This is the basic idea Nested Routed.
* Example :- /api/users/143/posts/467
* So, in this example we are trying to extract user with his id then his specific post with id, so now it is clear that what is nested routes.
* NOTE -> Nested Routes are some practice not a strict route type.
