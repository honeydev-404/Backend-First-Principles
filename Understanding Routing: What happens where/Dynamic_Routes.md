Dynamic Routes ->
* Suppose you have multiple users and you cannot assign big values to them because that will be difficult to handle and understand and that will not be good for routes so we can assign numbers instead. 
* So, we have :- GET /users/123.  ->   GET /users/:id  
* From the above example that we are fetching user whose id = 123 but there are many users with different id’s. So from this we understand that id: parameter is a variable because it changes depending one which user we are trying to fetch.
* So, Dynamic Routes have a variable part and this is very important concept in Routing.
* And remember route parameters are strings.
